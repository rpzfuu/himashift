# L11 - Browser & Asset Verification Checklist

Isi manual setelah buka app di browser.

## Login Page

- [ ] Admin login CSS tampil.
- [ ] Mahasiswa login CSS tampil.
- [ ] Logo/favicon tampil.
- [ ] Tidak ada console error.
- [ ] Tidak ada asset 404 di Network tab.

## Forms

- [ ] Field kosong menampilkan error/feedback yang dapat diterima untuk arsip.
- [ ] Login valid redirect smooth.
- [ ] Flash/session behavior normal.

## List Pages

- [ ] Tabel mahasiswa render rapi.
- [ ] Tabel event render rapi.
- [ ] Tabel absen render rapi.
- [ ] Tombol action terlihat.

## Edit Forms

- [ ] Field mahasiswa pre-filled.
- [ ] Field event pre-filled.
- [ ] Field absen pre-filled.
- [ ] Submit update sukses.

## PDF

- [ ] Sertifikat terbuka inline/download.
- [ ] Nama mahasiswa benar.
- [ ] Nama acara/jobdesk/tanggal benar.
- [ ] PDF tidak corrupt di browser.
- [ ] PDF tidak corrupt di Adobe Reader atau PDF viewer lain.

## Responsive

- [ ] Mobile 375px.
- [ ] Tablet 768px.
- [ ] Desktop.

## Cross Browser

- [ ] Chrome.
- [ ] Firefox.
- [ ] Edge.
